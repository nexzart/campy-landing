Printing ID cards at the right size

  1. Press Print cards. Each front is printed next to its back.
  2. In the print dialog, set the scale to 100% (or “Actual size”). Turn off “Fit to page”, which shrinks the cards.
  3. Print on thick paper or card stock (250–300 gsm), cut along the edges and laminate. To make a double-sided card, fold along the middle before laminating.

What a student ID card should show

  • The school’s name and logo, and the student’s photo, name and class
  • Admission number and date of birth
  • Blood group and an emergency contact, which help in a medical emergency
  • The school’s address and phone number, so a lost card can be returned
