How weighted GPA is calculated

GPA = Σ (grade points × credits) ÷ Σ credits

An A (4.0) in a 4-credit course and a B (3.0) in a 3-credit course give (16 + 9) ÷ 7 = 3.57.

Some schools add extra points for honours, AP or IB Higher Level courses (a “weighted” 5.0 scale). This calculator uses the standard unweighted 4.0 scale.
